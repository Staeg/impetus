The following affect specific factions. Any references to game effects should assume that they solely affect the faction that has been Shaped with the card unless stated otherwise.

# Glory in War

Short description for card text body: Spoils drawn twice
Full on-hover text and gameplay effect: When drawing Spoils of War, draw and resolve an additional Agenda card from your Agenda pool.

# Pyrrhic Defeat

Short description for card text body: Spoils draw after losing
Full on-hover text and gameplay effect: Also draw Spoils of War when losing a War.

# Fair Weather Friends

Short description for card text body: +Regard with stronger and -Regard with weaker neighbors
Full on-hover text and gameplay effect: Double the Regard gained with stronger factions. Double the Regard lost with weaker factions.

# Hellbound

Short description for card text body: Can't gain Regard
Full on-hover text and gameplay effect: Cannot gain Regard with other factions, even if the source of that Regard is another faction.

# Turn the Other Cheek

Short description for card text body: Reset Regard after War
Full on-hover text and gameplay effect: After one of your Wars resolves, gain Regard with the opposing Faction equal to the current negative Regard with them.

# Amplified Steal

Short description for card text body: Steal resolves twice
Full on-hover text and gameplay effect: When resolving a Steal Agenda, resolve it an additional time.

# Amplified Change

Short description for card text body: Change resolves twice
Full on-hover text and gameplay effect: When resolving a Change Agenda, resolve it an additional time.

# Amplified Trade

Short description for card text body: Trade resolves twice
Full on-hover text and gameplay effect: When resolving a Trade Agenda, resolve it an additional time.

# Amplified Expand

Short description for card text body: Expand resolves twice
Full on-hover text and gameplay effect: When resolving an Expand Agenda, resolve it an additional time.

# Globalization

Short description for card text body: Steal from everyone
Full on-hover text and gameplay effect: Steal Agendas also affect factions that this faction is not neighbors with. Wars do not get declared with non-neighbors.

# Havoc

Short description for card text body: Change randomizes an Idol
Full on-hover text and gameplay effect: Change Agendas also switch the type of a random idol within this faction's territory to one of the other 2 types at random.

# Unilateral Agreement

Short description for card text body: Trade benefits from other Expands
Full on-hover text and gameplay effect: Trade Agendas also get bonuses from other factions' Expand Agendas.

# Special Military Operations

Short description for card text body: Expand can target non-neutral territories
Full on-hover text and gameplay effect: Expand Agendas can take over other factions' territories even without a War.
