The following affect specific spirits. Any references to game effects should assume that they affect the spirit that has Adapted with the card unless stated otherwise.

# Mesa Devotion

Short description for card text body: +VP from Mesa, -VP from others
Full on-hover text and gameplay effect: VP gained from the Mesa faction is tripled. VP gained from other factions is halved.

# Changer of Ways

Short description for card text body: Swap more Agendas when ejecting
Full on-hover text and gameplay effect: When Ejecting, replace an Agenda in the Faction's Agenda Pool an additional time.

# Battle Blessing

Short description for card text body: Affect War results more
Full on-hover text and gameplay effect: Triple your influence on the results of a War: when you would add an additional die to a Faction's power, instead add 3 such dice.

# Usurper

Short description for card text body: Gain more VP from others' Idols
Full on-hover text and gameplay effect: You gain full VP from Idols in Factions which Worship you, even if you do not own the Idol. The original owner still gets their 50% share.
